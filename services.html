How I can help

Four things I can actually build for you.

Not a full-service agency list — the services below are the ones RentManager is direct evidence for. If what you need doesn't fit one of these, ask anyway; I'll tell you honestly if it's outside what I can do well right now.

01

SaaS product development

For a founder or business that needs a real product built — not a landing page, the actual application. I design the data model, build the backend and its APIs, build the frontend that talks to it, and wire up authentication, so what you get is a working system end to end, not a prototype someone else has to finish.

02

Business workflow systems

If your operation currently runs on spreadsheets, WhatsApp threads, and someone's memory, that's a sign the workflow is real but the software behind it isn't. I turn that into an actual system: a data model that reflects how the business really runs, a dashboard that shows the state that matters, and an audit trail so "what happened to this record" has an answer.

03

Backend & API engineering

Spring Boot services built around a clear domain model rather than a pile of controllers — proper module boundaries, a schema that evolves through migrations you can read back like a history, and authorization enforced at the data-access layer, not just hidden behind a button in the UI.

04

Payment & third-party integrations

Specifically M-Pesa Daraja — STK push, B2C payouts, callback handling — built the way a payment integration has to be built: idempotent, so a retried request can't charge or pay twice, and auditable, so every transaction can be traced back to what triggered it.
