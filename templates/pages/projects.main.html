RentManager

Deployed · Live

A rental-management platform for Kenyan landlords and tenants, covering properties, units, leases, an M-Pesa-driven rent ledger, commission and payouts, and Kenya’s monthly rental-income tax rules. A Java and Spring Boot backend serves both a Next.js web app and a React Native mobile app.

Lovora

Private product · live

A private shared world for two: realtime chat, encrypted peer-to-peer calls, synchronised listening and watching, memories, and discoveries from the real world. It is a Next.js and TypeScript app with a tested sync protocol underneath the room.

The engineering that matters is in the quiet parts. Messages carry a device-made id so a retry is stored once, call audio and video go directly between browsers, and every personal item has a visibility rule enforced in one place rather than at each screen. The data layer runs on PGlite locally and Postgres in production.
